# Corin - Dockerised Demo Branch

This branch is for the dockerised demo of Corin, based on the working_demo branch. Changes made to this branch will be reflected when the docker image is built, so make them thoughtfully!

The original author of much of this code was Dr Wei Cheah. It is now being maintained by Daniel Derwent on behalf of the Centre for Robotics and AI at the University of Manchester. I can be contacted at: [daniel.derwent@manchester.ac.uk](daniel.derwent@manchester.ac.uk).

Work is planned to develop new drivers for Corin based on the [Smart Arm Stack](https://smartarmstack.github.io/), which may see the other branches of this repo replaced or pruned. However, this branch is likely to remain for demonstration purposes even after the new divers are developed.

For information on how the dockerised demo may be used, please see the dedicated repo of which this branch is a sub-module.
